# 영웅·신화 통합 종합 요약

사용자는 다른 화면의 디자인은 유지하면서 종합 요약에서 영웅·신화를 한눈에 비교하기를 요청했다. 두 개의 긴 표를 캐릭터 13행의 통합 표로 바꾸었다. 각 난이도는 최고/중앙값 백분위, 종합 점수, 순위 세 칸을 갖는다. 본문 수치는 16px, 점수·순위는 17px이며, 상단 설명과 도구는 한 줄로 줄였다. 상세 성적표, 우측 목차, 글꼴 자산, 수집기·워크플로는 변경하지 않는다.

기본 피해 지표는 전체 피해이며, 우두머리 피해 버튼으로 명시적으로 전환할 수 있다. 힐러는 항상 치유량이다. 전문화·난이도·지표·패치가 일치하는 점수/순위만 한 쌍으로 표시한다. 파멸과 포식은 두 줄로 유지하고 주 전문화를 정하지 않는다. 선택한 패치에 값이 없으면 빈칸이며 이전 패치 점수로 대체하거나 합산하지 않는다. 백분위는 기존 WCL 요약값을 그대로 사용하고, 패치 선택은 종합 점수와 순위에 적용된다고 화면에 안내한다.

배포된 공개 스냅샷에서 공식 WCL 메타를 읽었다. `checkedAt=2026-10-17T02:54:46.405Z`, 공격대 53의 ID 1=12.1, ID 2=12.1.5였다. 기존 캐릭터·전문화 표본과 수집 시각이 로컬 캐시와 완전히 일치함을 확인한 뒤 이 이름 메타만 로컬 미리보기에 연결했다. 새 게임 API 호출은 없다. 기본 선택은 ID 크기가 아니라 공식 버전명 숫자 순서에 따라 12.1.5다. 과거 버전은 선택기와 ‘전체 패치 기록’ 펼침에서 볼 수 있다. 공식 이름이 없으면 버전을 추측하지 않는다.

모바일 전체 요약은 기존 영웅/신화·피해 지표 탭을 유지하고 큰 점수 카드 대신 전문화별 한 줄 점수·순위를 사용한다. 모바일에서도 같은 패치 선택기와 전체 패치 펼침에 접근할 수 있다.

실제 Chrome 측정 결과, 1180/1366/1440/1920px에서 종합 요약 높이는 **2558.23px → 692.98px (72.9% 감소)**, 기본 표는 **26행 → 13행**으로 줄었다. 표 본문은 모두 16px이고 표의 가로 넘침은 0이었다. 1440×900과 1920×1080에서는 처음 화면에서도 마지막 캐릭터 행의 아래쪽이 약 857px여서 13명의 영웅·신화가 함께 보인다. 1180/1366에서는 기존 상단 헤더·캐릭터 바로가기가 차지하는 공간 때문에 화면 맨 위에서 약간 스크롤해야 하지만, 요약 자체는 같은 693px 영역 안에서 두 난이도를 비교한다.

수치 검증은 실제 캐시 520개 보스 행과, 두 피해 지표 × 두 패치의 84개 요약 슬롯 각각을 원본과 비교한다. 펼침 기록도 원본 점수·순위 목록과 비교한다. 테스트의 합성 버전명은 정렬/빈 값/지표 격리만 확인하며 실제 캐시에 저장하지 않는다.
