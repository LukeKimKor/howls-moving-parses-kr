# 표와 카드 디자인 정돈

사용자가 지정한 [전사 세팅 제보 페이지](https://erinndata.pages.dev/contribute/?cls=%EC%A0%84%EC%82%AC)를 로그인 없는 새 Chrome에서 읽기 전용으로 확인했다. 입력·제출·팔로우·메시지 작성은 하지 않았다. 본문은 Pretendard Variable 14px, 배경은 `rgb(14,18,33)`, 카드에는 낮은 대비의 테두리와 부드러운 모서리를 사용했다. 사이트의 폼이나 자산을 복제하지 않고 표면·간격·정보 위계만 참고했다.

와우 대시보드는 기존 A 디자인의 보라색 영웅/청록색 신화 구분, 직업 색상, Pretendard 계열 글리프, 본문·표 수치 16px, 우측 목차를 유지한다. 남색 바탕 위에 단계별 카드 표면을 두고 세로 격자선을 줄였다. 난이도 제목에는 가는 구분선을 넣고 All Stars 수치는 굵고 크게 표시한다. 후속 요청에 따라 종합 요약은 영웅·신화를 한 행에 놓는 13행 통합 표로 다시 줄였으며, 지표·패치 선택과 펼침 기록으로 원정보를 유지한다.

값이 없는 표 셀의 `—`, `-/-` 등은 빈칸으로 표시한다. `MissingValue`의 접근성 레이블은 남아 있고 실제 0은 사라지지 않는다. 두 백분위가 모두 없으면 `/`도 표시하지 않는다. 보스 미처치의 실제 처치 수 0, 부분 조회·실패·캐시 재사용 알림, 전문화 미확정 안내는 유지한다. 실제 로그의 피해량 0과 쐐기 점수 0은 보존한다.

현재 All Stars의 공식 패치명 연결은 별도 미확인 사항이며 [집계 범위 조사](all-stars.md)에 기록했다. 데이터 수집, 캐릭터 설정, API 접근, 워크플로 및 90점 성능 기준을 바꾸지 않는다.
