# Selected A layout and typography

The owner selected proposal A: a compact dark analysis layout. The subsequent readability update uses 60px desktop rows, 16px table values and a fixed PC table of contents on the right. Paired difficulty panels require 1800px of viewport width; narrower desktops show wider single-column cards. See [readability and reference measurements](readability.md). The Korean interface, verified encounter names and missing-data icon rules are included. Mobile character/spec/difficulty/metric selection and detailed panels remain available. _(2026-10-23 상세 페이지 제거 전 기록 — 현재 구성은 [docs/admin-guidelines.md](admin-guidelines.md) 참고)_

Pretendard Variable **1.3.9** is redistributed as 92 unmodified dynamic subsets from the [official release](https://github.com/orioncactus/pretendard/tree/v1.3.9/packages/pretendard/dist/web/variable/woff2-dynamic-subset). Every font file is checked against its official Git blob SHA; the complete list is in [the manifest](../public/fonts/manifest.json). The fonts are self-hosted under `public/fonts/dynamic/`, with the complete original copyright notice and [SIL OFL 1.1 license](../public/fonts/OFL-Pretendard.txt) next to them. No font package or system font is installed, and the application does not contact a font CDN.

The original 2.06MB whole-font preload caused an approximately 11.7s simulated mobile LCP. A **98,492-byte UI core** (2026-10-23) now combines the 428 code points used by the application source and registered character names, including the All Stars and empty-cell interface. Glyph outlines, advances, hinting, layout features (including tabular figures), variable weights and `font-display: swap` are retained. Representative outlines and advances are compared to the original at weights 400/500/650/700.

The core is a modified font under the distinct primary family **HMP Dashboard Sans**, following the OFL Reserved Font Name rule; it uses the selected Pretendard design, not new glyph designs. Copyright and licensing remain intact. Its [manifest](../public/fonts/core-manifest.json) and [FONTLOG](../public/fonts/FONTLOG.txt) document the derivation. The primary UI core is the only preloaded font. Original official subsets remain as fallback for code points absent from the core, so future character, item and player names keep the same design. See [performance investigation](performance.md).

`src/pretendard-subsets.css` keeps the official variable weight range (45–920), `font-display: swap` and unicode ranges. `src/typography.css` declares the UI core and retains the original family and platform fonts as fallbacks. Body copy uses weight 400, table/navigation labels 500, headings and numeric summaries 650, and the page title 700. Numeric values use `tabular-nums lining-nums`; Korean labels keep whole words where possible. No source data, API identifiers, collection settings, credentials or scheduled refresh policy are changed.

The production build contains the selected layout directly. The discarded B proposal and old comparison screenshots remain local verification artifacts and are not deployed.

Character sections use their actual layout height so native table-of-contents links remain accurate after font loading; the former estimated offscreen height could land a link on the preceding character. The scroll position indicator also handles a short final section at the bottom of the page.
