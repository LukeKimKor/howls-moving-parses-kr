# All Stars 표시와 집계 범위

## 구현

- 종합 요약은 영웅·신화 각각 13행 표를 사용한다. 치유량 오른쪽에 종합 점수와 WCL 순위가 있다. 본문 16px, 오른쪽 목차, 선택한 A 색상과 Pretendard 계열 폰트는 유지한다.
- 요약의 All Stars 기준은 공격 전문화 `dps`, 치유 전문화 `hps`이다. 각 전문화와 패치의 점수·순위 쌍을 그대로 표시한다. `bossdps` 값은 해당 상세 성적표에 계속 표시한다. 다른 전문화·난이도·지표·패치의 값을 합산하거나 가장 큰 점수를 임의 선택하지 않는다.
- 데스크톱과 모바일의 각 성적표에 공격대 종합 점수·순위 카드를 노출한다. 보스 표의 점수·순위는 별도 강조한다. 모바일의 보스 상세와 전체 캐릭터 요약에도 유지한다.
- 미확인 표 셀은 시각적으로 비우고 접근성 레이블을 제공한다. 실제 0은 `0`으로 구분한다. 파멸과 포식은 별도 전문화이며 주 전문화를 정하지 않는다.

## 실제 캐시 조사

원본: 공개 실행 #8의 실제 스냅샷, `generatedAt=2026-10-17T00:01:59.285Z`. 이번 변경은 수집을 실행하지 않는다.

- 공격대 53, The Venomous Abyss. 13명·14전문화·52개 지표/난이도 응답·520개 보스 행을 보존한다.
- 현재 `zoneRankings` 호출은 `zoneID`, `difficulty`, `metric`, `specName`을 지정하고 `partition`과 `timeframe`을 생략한다. 이를 ‘전체 패치’ 또는 ‘현재 패치’ 요청이라고 단정하지 않는다.
- 응답의 상위 `partition`은 모두 -1이다. 요약 `allStars[]`의 개별 점수·순위에는 구분 ID 1 또는 2가 있다. 이름은 캐시에 없다. 배열의 순서나 점수 크기로 패치를 추론하지 않는다.
- 예: 오렌지크림피자·비전·영웅·전체 피해는 ID 2 점수 897.969/순위 16, ID 1 점수 1017.71/순위 308이다. 둘은 각각 한 쌍이며 합계가 아니다. 화면 소수 둘째 자리 반올림은 표시 형식일 뿐 원본 숫자는 그대로 둔다.
- 보스 행의 `allStarPoints`와 `allStarRank`는 같은 원본 행에서 온 쌍이다. 그러나 행별 All Stars의 구분 ID는 기존 매퍼가 보존하지 않아, 보스 점수의 패치명은 확인할 수 없다. 이를 요약의 특정 패치 값과 동일하다고 주장하지 않는다.
- 보존된 순위는 WCL `rank`다. `regionRank`/`serverRank`는 현재 스냅샷에 없어 KR 순위나 서버 순위라고 바꾸어 표시하지 않는다.

## 패치 이름 확인 상태

공식 WCL [맹독 심연 순위 페이지](https://www.warcraftlogs.com/zone/rankings/53)의 검색 색인에는 12.1과 12.1.5 옵션이 있다. 하지만 ID 1/2와 각 표시명의 연결은 확인되지 않았다. 공식 페이지/문서는 직접 열기에서 HTTP 403이 반환되어 다른 클라이언트나 인증으로 우회하지 않았다. 새 API 인증 또는 데이터 재수집도 하지 않았다.

따라서 UI에서 기술 용어 대신 `패치명 미확인`을 사용한다. `src/lib/all-stars.ts`의 `verifiedPatchNames`에는 확인되지 않은 매핑을 넣지 않는다. 버전명을 완성하려면 기존에 승인된 접근으로 WCL 공격대 53의 구분 ID별 공식 이름을 확인해 이 맵을 채워야 한다. -1은 `전체 패치`로 매핑하지 않는다.

## 공식 의미 근거

- [WCL/Archon Rankings and Parses 안내](https://www.archon.gg/wow/articles/help/rankings-and-parses): 밸런스 변경 시 비교 구간을 나눌 수 있으며 All Stars 점수와 순위는 WCL 계산값이다. 직접 페이지 열기는 403이어서 공개 검색 색인으로 설명을 확인했다.
- [WCL 담당자 Vel의 All Stars 설명](https://forums.combatlogforums.com/t/how-is-the-overall-raid-allstar-points-computed/14340/4): 여러 구간의 All Stars 점수를 합산하지 않는다는 공식 담당자의 설명. 해당 글의 10.1.5 사례는 현재 공격대 53의 ID 매핑 근거로 사용하지 않는다.

테스트의 합성 데이터는 0/빈 값/전문화 격리를 검증하기 위한 것으로 실제 로그 파일에 저장하지 않는다.
