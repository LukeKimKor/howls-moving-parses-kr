Files: 92 official variable subsets, unchanged; per-file Git SHA and size in manifest.json.

The 92 official dynamic font files are redistributed unmodified. They are served with the application
from its own origin; no font CDN, package installation, or user font installation
is required. Variable weights 45-920 use the original supported range.

The official unicode-range declarations in src/pretendard-subsets.css allow the
browser to request only subsets containing characters it actually renders.
The fast UI core is a modified glyph subset under the distinct primary family
HMP Dashboard Sans, as required by the original Reserved Font Name. It retains
the original outlines, advances, hinting, layout features and variable weights.
See FONTLOG.txt and core-manifest.json for provenance and validation.
Only this 96,944-byte UI core is preloaded. Other glyphs use the original official
subsets on demand. The previous 2,057,688-byte whole font is no longer shipped.
